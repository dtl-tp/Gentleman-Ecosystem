# Frontend Design (UI/UX Pro Max)

## Goal
To guarantee that generated user interfaces meet the standards of a professional design agency, incorporating modern aesthetics, animations, and high-quality UX flows, while strictly avoiding generic or MVP visual states.

## Instructions
1. **Establish the Visual Language**: Define a cohesive color palette (HSL or Hex tailored colors), typography (e.g., modern sans-serifs like Inter, Roboto, or Outfit), and spacing system (CSS variables / tokens).
2. **Implement Premium Patterns**:
    - Use subtle glassmorphism, depth (shadows), and smooth gradients where appropriate.
    - Structure layouts using robust Flexbox or CSS Grid foundations.
    - Ensure all interactive elements (buttons, cards, links) have distinct `hover`, `focus`, and `active` states.
3. **Add Micro-Interactions**: Define smooth CSS transitions (e.g., `transition: all 0.2s ease-in-out`) to make the interface feel responsive and alive.
4. **Enforce Responsiveness**: Design mobile-first or ensure seamless scaling across desktop, tablet, and mobile views.
5. **Avoid Defaults**: Never use plain browser defaults for buttons, inputs, or typography. 

## Constraints
- Do not deliver a "simple prototype". The output must feel premium.
- Ensure color contrast meets accessibility standards while maintaining aesthetic appeal.
- Always include CSS structural rules before applying utility classes or inline styles.
