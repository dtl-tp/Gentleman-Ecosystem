# replica-entrepreneur

> **PHILOSOPHY: A COMMODITY CLONE HAS NO REASON TO EXIST.**
> Building an identical copy only competes on price.
> We listen to what users hate about the incumbent and build the exact solution they are begging for.

Reads `replica/reviews.csv`.
Writes `replica/feedback.md` and `replica/fixes.md`.

Tool in `tools/`:
```bash
python tools/reviews.py replica/reviews.csv --out replica/feedback.md
```

---

## 1. Truth in Research Rules (MANDATORY)

- **Zero Hallucination:** Never fabricate reviews, ratings, user quotes, or complaint statistics. If data cannot be found, state it clearly.
- **Verbatim & Linked:** Every single entry in `replica/reviews.csv` must include the direct URL and the exact quote. `reviews.py` automatically purges unlinked rows.
- **Human Reading over Scraping:** Read review portals via official feeds, public APIs (e.g. Hacker News Algolia, Apple RSS), or manual browser exploration.
- **Reviews are Research, Not Endorsements:** Competitor reviews guide engineering priorities. They are never published as testimonials on your landing page.

---

## 2. Review Gathering Workflow

Collect 50-100+ public reviews across at least three distinct sources:
- **G2, Capterra, Trustpilot:** Filter specifically for 2-star and 3-star reviews ("Love it, but..."). This is where product gaps hide.
- **Reddit & Hacker News:** Search queries like `"{app} alternative"`, `"{app} sucks"`, `"switched from {app}"`.
- **Public Roadmap / Feature Request Boards:** Canny, UserVoice, GitHub discussions (vote counts, oldest unresolved requests).
- **App Store / Play Store:** Recent critical reviews highlighting regressions or billing frustration.

Format entries in `replica/reviews.csv`:
```csv
source,url,date,rating,text
G2,https://g2.com/...,2026-03-15,2,"Price increased 40% after seat changes and no text notifications."
Reddit,https://reddit.com/...,2026-04-02,,"Support took 5 days to respond to a billing lock."
```

---

## 3. Clustering Pain Points (`reviews.py`)

Run the clustering tool:
```bash
python tools/reviews.py replica/reviews.csv --out replica/feedback.md
```

The script categorizes complaints into core themes:
1. **Pricing & Packaging:** Sudden per-seat increases, lock-in, predatory cancellation.
2. **Missing Capabilities:** Lack of SMS, poor calendar sync, weak webhooks.
3. **UX Friction:** Complex onboarding, slow UI, confusing timezone selectors.
4. **Reliability & Support:** Downtime, unresponsive tickets.

---

## 4. The Fix Plan & Positioning Angle (`fixes.md`)

Transform top pain points into engineering specs and marketing positioning:

```markdown
# Product Fixes & Competitive Angle

## Incumbent Weakness: Predatory Per-Seat Pricing
- Evidence: 42 linked complaints across G2 and Reddit.
- Our Fix: Flat monthly pricing for unlimited team members.
- Marketing Angle: "The scheduling tool built for growing agencies tired of per-seat penalties."

## Incumbent Weakness: Confusing Timezone Handling
- Evidence: 18 linked reviews reporting missed client calls.
- Our Fix: Explicit 2-step timezone confirmation modal displaying both host and guest local times.
- Marketing Angle: "Zero missed meetings across timezones."
```
